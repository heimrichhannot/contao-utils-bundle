SearchVectorIndexer
in package

SearchVectorIndexer.php : 30

Builds and stores the search vector of records whose table registered a SearchVectorField.

Format: the tokens of one value are joined by a space, values are separated by | and the whole string is wrapped in | … |, e.g. | fuhrung durch die altstadt | sommer | stadtrundgange | (without stemmer). The space keeps word adjacency for quoted phrase searches, the pipe stops a phrase from matching across two unrelated values.

Option labels are resolved and words are stemmed in the language of the record (see SearchVectorFieldConfiguration::setLanguage() and setLanguageField()), never in the language of the current user.

Rebuilds the search vector of a single record.

public index(string $table, int $id[, DataContainer|null $dc = null ]) : bool

The record is read from the database, so this can be called from any save path after the record was written. The record is locked while its vector is rebuilt, so a concurrent rebuild of the same record waits and then reads the newer data instead of being overwritten with an outdated vector.
